# Anss Studio — Premier Wedding Video Projects & 4K Stage LED Visuals

Ultra-modern, cinematic web platform for **Anss Studio Pvt. Ltd.** (Delhi), providing ready-to-use digital editing project packs for:
- **Adobe Premiere Pro**
- **Edius Pro (9 / 10 / 11)**
- **Adobe After Effects**
- **Apple Final Cut Pro (FCPX)**
- **4K Synchronized Stage LED Visuals (Center Screen, Left/Right Wings, Base Riser)**

## 🚀 Features
- 👑 **Cinematic Dark Luxury UI/UX** with responsive design for mobile, tablet, and 4K displays.
- ⚡ **Interactive 3D Stage LED Visualizer**: Live preview of 4-screen synchronized LED stage setups with theme switcher (Royal Varmala, Neon Sangeet, Sufi Night).
- 🎬 **Video Project Showcase & Live Demo Modal**: Watch previews directly on-site without page reloads.
- 🔍 **Instant Search & Category Filters**: Quickly find projects by editing software and keywords.
- 💬 **WhatsApp 1-Click Order & Instant UPI Download Flow**: Direct checkout to WhatsApp with pre-filled cart invoice.
- 📍 **Delhi Studio Location & Contact Module**: Direct phone, WhatsApp, office address, and consultation booking.

## 🛠️ Tech Stack
- HTML5, CSS3, Modern JavaScript (ES6+)
- Tailwind CSS
- Lucide Icons
- SEO Schema.org (LocalBusiness & DigitalProducts)
